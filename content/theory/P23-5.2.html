5.2 Integration of 1/(ax+b)

Based on Cambridge International AS & A Level Mathematics: Pure Mathematics 2 & 3 Coursebook (Sue Pemberton, Julianne Hughes), Chapter 5 Integration, pp.115–117 (Key points 5.2–5.3, Worked examples 5.4–5.5, Exercise 5B Q1–2). Own wording and new numbers.

Key words: natural logarithm, reverse chain rule, modulus, definite integral, constant of integration

The rule

We know \(\frac{\mathrm{d}}{\mathrm{d}x}(\ln x)=\frac1x\) for \(x>0\), and \(\frac{\mathrm{d}}{\mathrm{d}x}\ln(ax+b)=\frac{a}{ax+b}\) for \(ax+b>0\). Reversing these gives the natural logarithm results:

$$\int\frac1x\,\mathrm{d}x=\ln x+c\ (x>0),\qquad \int\frac{1}{ax+b}\,\mathrm{d}x=\frac1a\ln(ax+b)+c\ (a\neq0,\ ax+b>0)$$

The power rule cannot be used here: \(\int x^{-1}\,\mathrm{d}x\) would need division by \(-1+1=0\). As with exponentials, this is a reverse chain rule: divide by \(a\), the coefficient of \(x\). Always state where the answer is valid, for example \(x>-\frac12\) for \(\ln(2x+1)\).

The modulus version

\(\ln\) is only defined for positive numbers. When \(x \lt 0\), \(\frac{\mathrm{d}}{\mathrm{d}x}\ln(-x)=\frac1x\) as well, so:

$$\int\frac1x\,\mathrm{d}x=\ln|x|+c\ (x\neq0),\qquad \int\frac{1}{ax+b}\,\mathrm{d}x=\frac1a\ln|ax+b|+c\ (a\neq0,\ ax+b\neq0)$$

The general result holds on any interval on which \(ax+b\) is never zero.

The modulus sign is normally written when finding a definite integral, where the limits may make \(ax+b\) negative. The interval must not include the value where \(ax+b=0\).

Common mistakes

  • Multiplying by \(a\) instead of dividing: \(\int\frac{4}{2x+1}\,\mathrm{d}x=2\ln(2x+1)+c\), not \(8\ln(2x+1)+c\).
  • Losing the sign when \(a\) is negative: \(\int\frac{6}{2-3x}\,\mathrm{d}x=-2\ln(2-3x)+c\).
  • Taking out a factor wrongly: \(\frac{1}{2(3x+1)}=\frac12\times\frac{1}{3x+1}\), so the integral is \(\frac16\ln(3x+1)+c\).
  • Using \(\ln\) of a negative number in a definite integral: use \(\ln|ax+b|\).

Worked example 1: Indefinite integrals and where they are valid

Book: Worked example 5.4, pp.115–116; Exercise 5B Q1 p.117

Find each integral and state the values of \(x\) for which it is valid. (a) \(\int\frac{5}{x}\,\mathrm{d}x\) (b) \(\int\frac{8}{4x+1}\,\mathrm{d}x\)

  1. (a) \(5\ln x+c\), valid for \(x>0\) B1
  2. (b) \(8\times\frac14\ln(4x+1)+c\) M1
  3. \(=2\ln(4x+1)+c\), valid for \(x>-\frac14\) A1

Answer: (a) \(5\ln x+c,\ x>0\) (b) \(2\ln(4x+1)+c,\ x>-\frac14\)

Worked example 2: A negative coefficient of x

Book: Worked example 5.4c, p.116; Exercise 5B Q1e p.117

Find \(\int\frac{10}{3-5x}\,\mathrm{d}x\) and state the values of \(x\) for which it is valid.

  1. \(10\times\frac{{1}}{{-5}}\ln(3-5x)+c\) M1
  2. \(=-2\ln(3-5x)+c\), valid for \(3-5x>0\), that is \(x \lt \frac{3}{5}\) A1

Answer: \(-2\ln(3-5x)+c,\ x \lt \frac{3}{5}\)

Worked example 3: A definite integral

Book: Exercise 5B Q2 p.117

Find the exact value of \(\int_1^4\frac{6}{2x+1}\,\mathrm{d}x\).

  1. \(\left[3\ln(2x+1)\right]_1^4\) M1 A1
  2. \(=3\ln9-3\ln3=3\ln3\) M1
  3. \(=\ln27\) A1

Answer: \(\ln27\) (about 3.30)

Worked example 4: Using the modulus

Book: Key point 5.3 and Worked example 5.5, p.117

Find the exact value of \(\int_3^5\frac{4}{1-2x}\,\mathrm{d}x\).

  1. On \(3\le x\le5\), \(1-2x\) is negative, so use \(\ln|1-2x|\)
  2. \(\left[-2\ln|1-2x|\right]_3^5=-2\ln9+2\ln5\) M1 A1
  3. \(=2\ln\frac59\) A1

Answer: \(2\ln\frac59\) (about \(-1.18\))

Quick checks

Quick check 1

Find \(\int\frac{12}{4x-3}\,\mathrm{d}x\) and state where the result is valid.

Worked solution
  1. \(12\times\frac14\ln(4x-3)+c\)
  2. \(=3\ln(4x-3)+c\), valid for \(x>\frac34\) (or \(3\ln|4x-3|+c\) for \(x\neq\frac34\))

Answer: \(3\ln(4x-3)+c\), valid for \(x>\frac34\)

Quick check 2

Evaluate \(\int_0^3\frac{2}{x+1}\,\mathrm{d}x\), giving your answer correct to 3 significant figures.

Worked solution
  1. \(\left[2\ln(x+1)\right]_0^3=2\ln4-2\ln1=2\ln4\)
  2. \(=2.7725\ldots=2.77\)

Answer: \(2.77\)

Quick check 3

Evaluate \(\int_2^4\frac{3}{6-x}\,\mathrm{d}x\), giving your answer correct to 3 significant figures.

Worked solution
  1. \(\left[-3\ln(6-x)\right]_2^4=-3\ln2+3\ln4\)
  2. \(=3\ln2=2.0794\ldots=2.08\)

Answer: \(2.08\)

Quick check 4

Evaluate \(\int_{-4}^{-1}\frac{4}{x}\,\mathrm{d}x\), giving your answer correct to 3 significant figures.

Worked solution
  1. \(\left[4\ln|x|\right]_{-4}^{-1}=4\ln1-4\ln4\)
  2. \(=-4\ln4=-5.5451\ldots=-5.55\)

Answer: \(-5.55\)

Marks: M = method, A = accurate answer (depends on M), B = independent mark. Exact answers are left in terms of \(\ln\); decimal answers to 3 s.f.
