10.1 The technique of separating the variables

Based on Cambridge International AS & A Level Mathematics: Pure Mathematics 2 & 3 Coursebook (Sue Pemberton, series editor Julian Gilbey), Chapter 10 Differential equations, printed pp.245–251. Own wording and new numbers, following the coursebook method of separating the variables, finding the general solution and then a particular solution.

Key words: differential equation, separating the variables, general solution, particular solution, constant of integration

Differential equations

A differential equation is an equation that contains a derivative such as \(\dfrac{dy}{dx}\). Solving it means finding \(y\) in terms of \(x\) without any derivatives.

Separating the variables

If the equation can be written as \(\dfrac{dy}{dx}=f(x)\,g(y)\), we solve it by separating the variables: put all the \(y\) terms with \(dy\) on one side and all the \(x\) terms with \(dx\) on the other, then integrate both sides.

\[\int\frac{1}{g(y)}\,dy=\int f(x)\,dx\]

Only one constant of integration is needed, written on the \(x\) side. The answer with this arbitrary constant is the general solution. A given condition, such as \(y=2\) when \(x=0\), fixes the constant and gives a particular solution. Then rearrange to give \(y\) in terms of \(x\) if the question asks for it.

Worked example 1: An exponential solution

Coursebook, 10.1, separating the variables. New numbers.

Solve \(\dfrac{dy}{dx}=2xy\), given that \(y=3\) when \(x=0\). Give \(y\) in terms of \(x\).

  1. \(\displaystyle\int\frac{1}{y}\,dy=\int2x\,dx\) B1
  2. \(\ln y=x^2+c\) B1
  3. \(x=0\), \(y=3\): \(c=\ln3\) M1
  4. \(y=\mathrm{e}^{x^2+\ln3}=3\mathrm{e}^{x^2}\) A1

Answer: \(y=3\mathrm{e}^{x^2}\)

Worked example 2: A square-root solution

Coursebook, 10.1, particular solution. New numbers.

Solve \(\dfrac{dy}{dx}=\dfrac{6x^2}{y}\), where \(y\gt 0\), given that \(y=2\) when \(x=0\).

  1. \(\displaystyle\int y\,dy=\int6x^2\,dx\) B1
  2. \(\tfrac{1}{2}y^2=2x^3+c\) B1
  3. \(x=0\), \(y=2\): \(c=2\) M1
  4. \(y^2=4x^3+4\), so \(y=2\sqrt{x^3+1}\) A1

Answer: \(y=2\sqrt{x^3+1}\)

Common mistakes

  • Integrating \(\dfrac{1}{y}\) as \(y^{-2}\) or forgetting that it gives \(\ln y\).
  • Adding the constant after rearranging, for example writing y = e^(x²) + c instead of finding c in ln y = x² + c.
  • Not using the given condition, so leaving a general solution when a particular solution is asked for.

\(\displaystyle\frac{dy}{dx}=\mathrm{e}^{2x+y},\)

Mark scheme

  2. \(-\mathrm{e}^{-y}\) B1 Official MS: B1, obtain term −e^(−y), or equivalent.
  3. \(\tfrac{1}{2}\mathrm{e}^{2x}\) B1 Official MS: B1, obtain term ½e^(2x), or equivalent.
  4. \(x=0\), \(y=0\): \(-1=\tfrac{1}{2}+c\), so \(c=-\tfrac{3}{2}\) M1 Official MS: M1, evaluate a constant, or use limits x = 0, y = 0 in a solution containing terms ae^(−y) and be^(2x).

Quick check 1

The variables \(x\) and \(y\) satisfy \(\dfrac{dy}{dx}=0.3y\), and \(y=4\) when \(x=0\). Find the value of \(y\) when \(x=2\).

Worked solution
  1. \(\ln y=0.3x+C\), so \(y=4\mathrm{e}^{0.3x}\)
  2. \(y=4\mathrm{e}^{0.6}\)

Answer: \(7.29\) (3 s.f.)

Quick check 2

The variables \(x\) and \(y\) satisfy \(\dfrac{dy}{dx}=\dfrac{x}{y}\), where \(y\gt 0\), and \(y=3\) when \(x=0\). Find the value of \(y\) when \(x=4\).

Worked solution
  1. \(y^2=x^2+9\)
  2. \(y=\sqrt{16+9}\)

Answer: \(5\)

Quick check 3

The variables \(x\) and \(y\) satisfy \(\dfrac{dy}{dx}=\dfrac{2y}{x}\) for \(x\gt 0\), \(y\gt 0\), and \(y=3\) when \(x=1\). Find the value of \(y\) when \(x=2\).

Worked solution
  1. \(\ln y=2\ln x+C\), so \(y=3x^2\)

Answer: \(12\)
