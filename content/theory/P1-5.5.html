5.5 Inverse trigonometric functions

Based on Cambridge International AS & A Level Mathematics: Pure Mathematics 1 Coursebook (Sue Pemberton, series editor Julian Gilbey), Chapter 5 Trigonometry, printed pp.136–139 (physical PDF page = printed page + 12). Own wording and new numbers, following the coursebook definitions of \(\sin^{-1}\), \(\cos^{-1}\) and \(\tan^{-1}\) and their principal values.

Key words: inverse sine, inverse cosine, inverse tangent, principal value

Principal values

The functions \(y=\sin x\), \(y=\cos x\) and \(y=\tan x\) are not one-to-one on the whole real line, so they do not have inverses unless the domain is restricted. The usual restrictions, and the corresponding inverse functions, are as follows.

  • \(\sin^{-1}x\) (also written \(\arcsin x\)) is defined for \(-1\le x\le 1\), and its values (the principal values) lie in \(-\dfrac{\pi}{2}\le\sin^{-1}x\le\dfrac{\pi}{2}\), or \(-90^\circ\le\sin^{-1}x\le 90^\circ\).
  • \(\cos^{-1}x\) (also written \(\arccos x\)) is defined for \(-1\le x\le 1\), and its principal values lie in \(0\le\cos^{-1}x\le\pi\), or \(0^\circ\le\cos^{-1}x\le 180^\circ\).
  • \(\tan^{-1}x\) (also written \(\arctan x\)) is defined for all real \(x\), and its principal values lie in \(-\dfrac{\pi}{2}<\tan^{-1}x<\dfrac{\pi}{2}\), or \(-90^\circ<\tan^{-1}x<90^\circ\).

The three inverse functions are the inverse sine, the inverse cosine and the inverse tangent.

For example, \(\sin^{-1}\bigl(\tfrac{1}{2}\bigr)=30^\circ\) (or \(\dfrac{\pi}{6}\)), not \(150^\circ\), even though \(\sin 150^\circ=\tfrac{1}{2}\) as well. If an angle is given as \(\theta=\cos^{-1}k\) with \(k>0\), then \(\theta\) is acute, and a right-angled triangle can be used to find exact values of \(\sin\theta\) and \(\tan\theta\) without a calculator.

Worked example 1: A principal value in degrees

Coursebook, 5.5, principal-value style. New evaluation of \(\sin^{-1}\bigl(\dfrac{\sqrt{3}}{2}\bigr)\).

Find the principal value of \(\sin^{-1}\bigl(\dfrac{\sqrt{3}}{2}\bigr)\), in degrees.

  1. \(\sin 60^\circ=\dfrac{\sqrt{3}}{2}\), and \(60^\circ\) lies in the interval \([-90^\circ,90^\circ]\), so the principal value is \(60^\circ\). B1

Answer: \(60^\circ\)

Worked example 2: Exact values from an inverse cosine

Coursebook, 5.5, triangle-from-an-inverse style. New value \(\theta=\cos^{-1}\bigl(\dfrac{3}{5}\bigr)\).

Given that \(\theta=\cos^{-1}\bigl(\dfrac{3}{5}\bigr)\), find the exact value of \(\sin\theta+\tan\theta\).

  1. A right-angled triangle with adjacent \(3\) and hypotenuse \(5\) has opposite side \(4\), and the principal value of \(\cos^{-1}\bigl(\dfrac{3}{5}\bigr)\) is acute, so \(\sin\theta=\dfrac{4}{5}\) and \(\tan\theta=\dfrac{4}{3}\). M1
  2. Hence \(\sin\theta+\tan\theta=\dfrac{4}{5}+\dfrac{4}{3}=\dfrac{12+20}{15}=\dfrac{32}{15}\). A1

Answer: \(\dfrac{32}{15}\)

Common mistakes

  • Giving a second-quadrant angle as the value of \(\sin^{-1}k\) when \(k\) is positive: the principal value is the acute angle, not \(180^\circ\) minus that angle.
  • Taking \(\cos^{-1}k\) to be negative when \(k\) is positive. Principal values of inverse cosine lie between \(0^\circ\) and \(180^\circ\).

Quick check 1

Given that \(\theta=\sin^{-1}\bigl(\dfrac{5}{13}\bigr)\) and \(\theta\) is acute, find the value of \(13\cos\theta\).

Worked solution
  1. A right-angled triangle with opposite \(5\) and hypotenuse \(13\) has adjacent side \(12\), so \(13\cos\theta=12\).

Answer: \(12\)

Quick check 2

Given that \(\theta=\cos^{-1}\bigl(\dfrac{7}{25}\bigr)\) and \(\theta\) is acute, find the value of \(25\sin\theta\).

Worked solution
  1. A right-angled triangle with adjacent \(7\) and hypotenuse \(25\) has opposite side \(24\), so \(25\sin\theta=24\).

Answer: \(24\)

Quick check 3

Given that \(\theta=\tan^{-1}\bigl(\dfrac{8}{15}\bigr)\) and \(\theta\) is acute, find the value of \(17\sin\theta\).

Worked solution
  1. A right-angled triangle with opposite \(8\) and adjacent \(15\) has hypotenuse \(17\), so \(17\sin\theta=8\).

Answer: \(8\)
