6.4 Confidence intervals for population proportion

Based on Cambridge International AS & A Level Mathematics: Probability & Statistics 2 Coursebook (Jayne Kranat), Chapter 6 Estimation, printed pp.138–142. Own wording and new numbers, following the coursebook use of the sample proportion as an estimate, the approximate interval p̂ ± z√(p̂(1 − p̂)/n) and how to use an interval to comment on a claim.

Key words: confidence interval, sample proportion, population proportion, standard error

Estimating a population proportion

Suppose a proportion \(p\) of a large population has some property. In a random sample of size \(n\), let \(X\) be the number with the property, so \(X\sim\mathrm{B}(n, p)\). The sample proportion \(\hat p=\dfrac{X}{n}\) is an unbiased estimate of the population proportion \(p\).

For large \(n\), \(\hat p\) is approximately normally distributed with mean \(p\) and variance \(\dfrac{p(1-p)}{n}\). Since \(p\) is unknown, its estimate \(\hat p\) is used in the variance. The square root of this estimated variance is the standard error.

The approximate confidence interval

An approximate confidence interval for \(p\) is

\[\hat p-z\sqrt{\frac{\hat p(1-\hat p)}{n}}\ \ \text{to}\ \ \hat p+z\sqrt{\frac{\hat p(1-\hat p)}{n}},\]

where \(z\) is the same value as for a mean, for example:

Level90%95%96%98%99%
\(z\)1.6451.962.0542.3262.576

The interval is approximate for two reasons: the normal distribution is used in place of the binomial, and \(\hat p\) is used in place of \(p\) in the standard error. The sample must be large.

Commenting on a claim

If a claimed value of \(p\) lies outside the interval, the claim is unlikely to be true. If it lies inside, there is no reason to doubt it. Do not say the claim is definitely true or false: the interval is only a range of plausible values.

Worked example 1: A 95% interval

Coursebook, 6.4, an approximate confidence interval for a proportion. New numbers.

In a random sample of 400 adults, 120 cycle to work. Calculate an approximate 95% confidence interval for the proportion of all adults who cycle to work.

  1. \(\hat p=\dfrac{120}{400}=0.3\) B1
  2. \(0.3\pm1.96\sqrt{\dfrac{0.3\times0.7}{400}}=0.3\pm1.96\times0.022913\) M1 B1
  3. \(=0.3\pm0.0449\), so \(0.255\) to \(0.345\) A1

Answer: \(0.255\) to \(0.345\) (3 s.f.)

Worked example 2: Using an interval

Coursebook, 6.4, using an interval to comment on a claim. New numbers.

Of 150 randomly chosen customers, 45 used a discount code. Calculate an approximate 99% confidence interval for the proportion of all customers who use a discount code, and comment on a claim that 40% of customers use one.

  1. \(\hat p=0.3\), \(0.3\pm2.576\sqrt{\dfrac{0.3\times0.7}{150}}=0.3\pm2.576\times0.037417\) M1 B1
  2. \(=0.3\pm0.0964\), so \(0.204\) to \(0.396\) A1
  3. \(0.4\) is not in the interval, so the claim is unlikely to be true B1

Answer: \(0.204\) to \(0.396\); the claim of 40% is unlikely to be true

Common mistakes

  • Using the number \(x\) instead of the proportion \(\dfrac{x}{n}\) in the formula.
  • Forgetting the square root, or dividing by \(n-1\) instead of \(n\).
  • Saying a claim is definitely true because the value lies inside the interval.

Quick check 1

In a random sample of 200 people, 60 were left-handed. Using \(z=1.96\), find the upper limit of an approximate 95% confidence interval for the proportion of people who are left-handed.

Worked solution
  1. \(\hat p=0.3\)
  2. \(\sqrt{\dfrac{0.3\times0.7}{200}}=0.032404\)
  3. \(0.3+1.96\times0.032404\)

Answer: \(0.364\) (3 s.f.)

Quick check 2

A die is thrown 300 times and shows a six on 60 throws. Using \(z=2.326\), find the lower limit of an approximate 98% confidence interval for the probability of a six.

Worked solution
  1. \(\hat p=0.2\)
  2. \(\sqrt{\dfrac{0.2\times0.8}{300}}=0.023094\)
  3. \(0.2-2.326\times0.023094\)

Answer: \(0.146\) (3 s.f.)

Quick check 3

In a random sample of 400 items, 160 were faulty. Using \(z=1.645\), find the width of an approximate 90% confidence interval for the proportion of faulty items.

Worked solution
  1. \(\hat p=0.4\)
  2. \(\sqrt{\dfrac{0.4\times0.6}{400}}=0.024495\)
  3. \(2\times1.645\times0.024495\)

Answer: \(0.0806\) (3 s.f.)
