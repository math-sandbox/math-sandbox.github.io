4.1 Experiments, events and outcomes

Based on Cambridge International AS & A Level Mathematics: Probability & Statistics 1 Coursebook (Dean Chalmers), Chapter 4 Probability, pp.91–94 (Key points 4.1–4.4, Worked example 4.1, Exercise 4A). Own wording and new numbers.

Key words: experiment, outcome, event, sample space, equally likely, complement, exhaustive, trial, relative frequency, expected frequency

Experiments, outcomes and events

An experiment is an action with an uncertain result, such as rolling a die. Each possible result is an outcome. An event is a set of one or more outcomes. Rolling an ordinary die has six outcomes: 1, 2, 3, 4, 5 and 6. The event “an odd number” has three favourable outcomes: 1, 3 and 5.

The list (or table) of all possible outcomes is the sample space, also called the possibility space. When two ordinary six-sided dice are thrown, the sample space is a grid of \(6\times6=36\) ordered pairs, because (2, 5) and (5, 2) are different outcomes.

Equally likely outcomes

Choosing at random means every object has the same chance of being chosen: the outcomes are equally likely. If one object is chosen at random from \(n\) objects, the probability of choosing any particular object is \(\dfrac1n\).

$$\mathrm{P}(\text{event})=\frac{\text{number of favourable equally likely outcomes}}{\text{total number of equally likely outcomes}}$$

A probability is between 0 (impossible) and 1 (certain). Give it as a fraction, a decimal or a percentage; in Cambridge answers give an exact fraction or a decimal correct to 3 significant figures.

Complement and exhaustive events

The complement of event \(A\), written \(A'\), is “\(A\) does not happen”. A set of events is exhaustive if it contains every possible outcome, so one of them must happen. \(A\) and \(A'\) are exhaustive and cannot both happen, so

$$\mathrm{P}(A)+\mathrm{P}(A')=1,\qquad \mathrm{P}(A')=1-\mathrm{P}(A).$$

In the same way, the probabilities of all the outcomes of an experiment add up to 1. This lets us find an unknown probability.

Trials, relative frequency and expectation

Each repeat of an experiment is a trial. The proportion of trials in which an event happens is its relative frequency; with many trials it is a good estimate of the probability. If \(\mathrm{P}(A)\) is known, then in \(n\) trials event \(A\) is expected to happen

$$n\times\mathrm{P}(A)\ \text{times}.$$

This expected frequency is an average over many repeats. It need not be a whole number, and the actual number of times can be different from it.

Worked example 1: One random selection

Book: Key points 4.1 and 4.2, pp.91–92; Exercise 4A p.93

A bag contains 5 red, 7 blue and 8 green counters. One counter is taken at random. Find the probability that it is (a) one particular counter, (b) blue, (c) not green.

  1. Total: \(5+7+8=20\) equally likely outcomes B1
  2. (a) \(\mathrm{P}(\text{particular counter})=\dfrac1{20}\) B1
  3. (b) \(\mathrm{P}(\text{blue})=\dfrac{7}{20}\) B1
  4. (c) \(\mathrm{P}(\text{not green})=1-\dfrac{8}{20}\) M1
  5. \(=\dfrac{12}{20}=\dfrac35\) A1

Answer: (a) \(\frac1{20}\) (b) \(\frac{7}{20}\) (c) \(\frac35\)

Worked example 3: Complement and expectation

Book: Worked example 4.1, p.93; Key point 4.4, p.92

The probability that a school bus is late on any particular day is 0.15. On how many of 220 school days is the bus expected not to be late?

  1. \(\mathrm{P}(\text{not late})=1-0.15=0.85\) B1
  2. \(220\times0.85\) M1
  3. \(=187\) days A1

Answer: 187 days

Worked example 4: Relative frequency as an estimate

Book: Trials and expectation, p.92; Explore 4.1, p.93

A drawing pin is dropped 400 times and lands point up 132 times. Estimate the probability that it lands point up, and the number of times it is expected to land point up in 1500 drops.

  1. Relative frequency \(=\dfrac{132}{400}=0.33\) B1
  2. \(1500\times0.33\) M1
  3. \(=495\) times A1

Answer: about 0.33; 495 times

Quick checks

Quick check 1

One student is chosen at random from a class of 14 boys and 21 girls. Find the probability that the student chosen is a girl.

Worked solution
  1. \(14+21=35\) equally likely outcomes, 21 favourable
  2. \(\mathrm{P}(\text{girl})=\dfrac{21}{35}=\dfrac35\)

Answer: 0.6

Quick check 2

The probability of rain on any particular day in a town is 0.35. On how many days is rain not expected in a period of 80 days?

Worked solution
  1. \(\mathrm{P}(\text{no rain})=1-0.35=0.65\)
  2. \(80\times0.65=52\)

Answer: 52 days

Quick check 3

Two fair six-sided dice, each with faces numbered 1 to 6, are thrown. Find the probability that at least one of the dice shows 6.

Worked solution
  1. Sample space: \(6\times6=36\) outcomes
  2. Neither die shows 6: \(5\times5=25\) outcomes, so \(36-25=11\) favourable outcomes
  3. \(\dfrac{11}{36}\approx0.306\)

Answer: \(\frac{11}{36}\approx0.306\)

Quick check 4

A biased spinner has four sections labelled 1, 2, 3 and 4. The probability that it lands on 1 is 0.2 and the probability that it lands on 2 is 0.35. Landing on 4 is twice as likely as landing on 3. Find the probability that the spinner lands on 4.

Worked solution
  1. Let \(\mathrm{P}(3)=x\), so \(\mathrm{P}(4)=2x\)
  2. \(0.2+0.35+x+2x=1\), so \(3x=0.45\) and \(x=0.15\)
  3. \(\mathrm{P}(4)=2x=0.3\)

Answer: 0.3
