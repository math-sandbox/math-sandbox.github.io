5.7 Trigonometric identities

Based on Cambridge International AS & A Level Mathematics: Pure Mathematics 1 Coursebook (Sue Pemberton, series editor Julian Gilbey), Chapter 5 Trigonometry, printed pp.145–148 (physical PDF page = printed page + 12). Own wording and new numbers, following the coursebook identities \(\sin^2\theta+\cos^2\theta=1\) and \(\tan\theta=\dfrac{\sin\theta}{\cos\theta}\), which are the identities required for Paper 1.

Key words: trigonometric identity

The standard identities

An identity is an equation that holds for every value of the variable for which both sides are defined. The identities used in this subsection are

\[\sin^2\theta+\cos^2\theta=1,\]

\[\tan\theta=\dfrac{\sin\theta}{\cos\theta}.\]

Each of these is a trigonometric identity. To prove an identity, one side is rewritten, using these facts, until it matches the other side. Substituting a single numerical value of \(\theta\) is not a proof.

Worked example 1: A short proof

Coursebook, 5.7, identity-proof style. New identity \(\cos^2\theta\tan^2\theta+\cos^2\theta=1\).

Prove the identity \(\cos^2\theta\tan^2\theta+\cos^2\theta=1\).

  1. The left-hand side is \(\cos^2\theta(\tan^2\theta+1)\). Replace \(\tan\theta\) by \(\dfrac{\sin\theta}{\cos\theta}\), to obtain \(\cos^2\theta\left(\dfrac{\sin^2\theta}{\cos^2\theta}+1\right)=\sin^2\theta+\cos^2\theta\). M1
  2. Hence the left-hand side is \(1\), which is the right-hand side. A1

Answer: \(\cos^2\theta\tan^2\theta+\cos^2\theta=\sin^2\theta+\cos^2\theta=1\)

Worked example 2: Using a known tangent

Coursebook, 5.7, numerical-identity style. New value \(\tan\theta=\dfrac{3}{4}\).

Given that \(\tan\theta=\dfrac{3}{4}\) and \(\theta\) is acute, find the value of \(5\sin\theta\).

  1. A right-angled triangle with opposite \(3\) and adjacent \(4\) has hypotenuse \(5\), so \(\sin\theta=\dfrac{3}{5}\). M1
  2. Hence \(5\sin\theta=3\). A1

Answer: \(3\)

Common mistakes

  • Treating a proof as if it were an equation to be solved, for example by starting with the identity and cancelling from both sides without a clear starting expression.
  • Using \(\sin^2\theta+\cos^2\theta=1\) as if it were \(\sin\theta+\cos\theta=1\).

Past paper

9709/12/O/N/10 Q2, official QP and official MS.

Prove the identity \(\tan^2 x-\sin^2 x\equiv\tan^2 x\sin^2 x\). [4]

Mark scheme
  1. The left-hand side is rewritten by replacing \(\tan^2 x\) by \(\dfrac{\sin^2 x}{\cos^2 x}\), or by \(\sec^2 x-1\). M1 Official MS: M1, replace \(t^2\) by \(s^2/c^2\) or \(\sec^2-1\).
  2. The factor \(1-\cos^2 x=\sin^2 x\) is used, to reach a form such as \(\dfrac{\sin^2 x(1-\cos^2 x)}{\cos^2 x}\). M1 Official MS: M1, use of \(1-\cos^2 x=\sin^2 x\).
  3. A valid overall method is completed, reaching \(\dfrac{\sin^2 x\sin^2 x}{\cos^2 x}\) or an equivalent. M1 Official MS: M1, valid overall method.
  4. The left-hand side is shown to be \(\tan^2 x\sin^2 x\). A1 Official MS: A1, AG. An equivalent sequence starting from the right-hand side is also given in the official MS.

Quick check 1

Given that \(\sin\theta=\dfrac{5}{13}\) and \(\theta\) is acute, find the value of \(13\cos\theta\).

Worked solution
  1. \(\cos^2\theta=1-\sin^2\theta=1-\dfrac{25}{169}=\dfrac{144}{169}\), and \(\theta\) is acute, so \(13\cos\theta=12\).

Answer: \(12\)

Quick check 2

Given that \(\tan\theta=\dfrac{5}{12}\) and \(\theta\) is acute, find the value of \(13\sin\theta\).

Worked solution
  1. A right-angled triangle with opposite \(5\) and adjacent \(12\) has hypotenuse \(13\), so \(13\sin\theta=5\).

Answer: \(5\)

Quick check 3

Given that \(\cos\theta=\dfrac{8}{17}\) and \(\theta\) is acute, find the value of \(289\sin^2\theta\).

Worked solution
  1. \(\sin^2\theta=1-\cos^2\theta=1-\dfrac{64}{289}=\dfrac{225}{289}\), so \(289\sin^2\theta=225\).

Answer: \(225\)
