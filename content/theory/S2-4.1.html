4.1 Introduction to continuous random variables

Based on Cambridge International AS & A Level Mathematics: Probability & Statistics 2 Coursebook (Jayne Kranat), Chapter 4 Continuous random variables, pp.76–82 (Key points 4.1–4.3, Worked examples 4.1–4.2, Exercise 4A). Own wording and new numbers.

Key words: continuous random variable, probability density function, probability density, normalising constant, area under the graph

From histograms to a density curve

A continuous random variable, such as a waiting time or a mass, can take any value in an interval. If we draw a histogram of many such values with probability density (relative frequency density) on the vertical axis, the total area of the bars is 1. As the class intervals get narrower, the tops of the bars approach a smooth curve \(y=\mathrm{f}(x)\). This curve is the probability density function (PDF) of \(X\).

Properties of a PDF

A function \(\mathrm{f}\) is a PDF only if both of these are true:

$$\mathrm{f}(x)\ge0\ \text{for all }x,\qquad \int_{-\infty}^{\infty}\mathrm{f}(x)\,\mathrm{d}x=1.$$

Usually \(\mathrm{f}(x)\) is non-zero only on a given interval and \(\mathrm{f}(x)=0\) otherwise, so we integrate over that interval only. A value of \(\mathrm{f}(x)\) is a density, not a probability, so it can be greater than 1. For example, \(\mathrm{f}(x)=2\) for \(0\le x\le0.5\) is a PDF.

If a PDF contains an unknown constant \(k\), we find \(k\) from the condition that the total area under the graph is 1. Here \(k\) is called a normalising constant.

Probabilities are areas

The probability that \(X\) lies in an interval is the area under the graph over that interval:

$$\mathrm{P}(a<X<b)=\int_a^b\mathrm{f}(x)\,\mathrm{d}x.$$

A single value has zero area, so \(\mathrm{P}(X=a)=0\) for every \(a\). (This does not mean that \(X\) cannot take the value \(a\).) It follows that \(<\) and \(\le\) give the same probability:

$$\mathrm{P}(a<X<b)=\mathrm{P}(a\le X<b)=\mathrm{P}(a<X\le b)=\mathrm{P}(a\le X\le b).$$

When the graph is made of straight lines, triangles, rectangles and trapezia often give the area faster than integration. For a PDF defined in pieces, integrate only the pieces inside the interval you need. Use \(\mathrm{P}(X>a)=1-\mathrm{P}(X\le a)\) when it is quicker. When you sketch a PDF, show only the part between the limits and label the important values on both axes.

Worked example 1: Finding k, then a probability

Book: Worked example 4.1, p.80; Exercise 4A Q1–2, p.82

\(X\) has PDF \(\mathrm{f}(x)=kx^3\) for \(0\le x\le2\), and \(\mathrm{f}(x)=0\) otherwise. (a) Find \(k\). (b) Find \(\mathrm{P}(X\ge1)\).

  1. (a) \(\displaystyle\int_0^2kx^3\,\mathrm{d}x=1\) M1
  2. \(k\left[\dfrac{x^4}{4}\right]_0^2=4k=1\) A1
  3. \(k=\dfrac14\) A1
  4. (b) \(\displaystyle\int_1^2\dfrac{x^3}{4}\,\mathrm{d}x=\left[\dfrac{x^4}{16}\right]_1^2\) M1
  5. \(=\dfrac{16}{16}-\dfrac{1}{16}=\dfrac{15}{16}\) A1

Answer: (a) \(k=\frac14\) (b) \(\frac{15}{16}\). The graph rises from \((0,\ 0)\) to \((2,\ 2)\); a density of 2 is allowed.

Worked example 2: Checking the properties on an infinite range

Book: Worked example 4.2 parts a–c, pp.81–82

\(X\) has PDF \(\mathrm{f}(x)=\dfrac{3}{x^4}\) for \(x\ge1\), and \(\mathrm{f}(x)=0\) otherwise. (a) Show that \(\mathrm{f}\) has the properties of a PDF. (b) Find \(\mathrm{P}(X>2)\).

  1. (a) \(x^4>0\), so \(\mathrm{f}(x)>0\) for \(x\ge1\); \(\mathrm{f}(x)=0\) elsewhere B1
  2. \(\displaystyle\int_1^{\infty}3x^{-4}\,\mathrm{d}x=\left[-x^{-3}\right]_1^{\infty}\) M1
  3. \(=0-(-1)=1\) A1
  4. (b) \(\displaystyle\int_2^{\infty}3x^{-4}\,\mathrm{d}x=\left[-x^{-3}\right]_2^{\infty}\) M1
  5. \(=0+\dfrac18=\dfrac18\) A1

Answer: (a) \(\mathrm{f}(x)\ge0\) and total area 1 (b) \(\frac18\)

Worked example 3: A PDF made of straight lines

Book: Section 4.1, pp.78–80 (taxi arrival time, Key points 4.1 and 4.3)

\(X\) has PDF \(\mathrm{f}(x)=\dfrac{x}{8}\) for \(0\le x\le2\), \(\mathrm{f}(x)=\dfrac14\) for \(2\le x\le4\), \(\mathrm{f}(x)=\dfrac{6-x}{8}\) for \(4\le x\le6\), and \(\mathrm{f}(x)=0\) otherwise. Check that the total area is 1, then find \(\mathrm{P}(1<X<5)\).

PieceShapeArea
\(0\le x\le2\)triangle\(\frac12\times2\times\frac14=\frac14\)
\(2\le x\le4\)rectangle\(2\times\frac14=\frac12\)
\(4\le x\le6\)triangle\(\frac12\times2\times\frac14=\frac14\)
  1. Total area \(=\dfrac14+\dfrac12+\dfrac14=1\), and \(\mathrm{f}(x)\ge0\) B1
  2. \(\mathrm{P}(X<1)=\dfrac12\times1\times\dfrac18=\dfrac{1}{16}\); by symmetry \(\mathrm{P}(X>5)=\dfrac{1}{16}\) M1
  3. \(\mathrm{P}(1<X<5)=1-\dfrac{1}{16}-\dfrac{1}{16}=\dfrac78\) A1

Answer: \(\frac78\)

Worked example 4: When a function is not a PDF

Book: Key point 4.1, p.79; Exercise 4A Q2a, p.82

Is \(\mathrm{f}(x)=x-\dfrac12\) for \(0\le x\le2\), and \(\mathrm{f}(x)=0\) otherwise, a PDF?

  1. \(\displaystyle\int_0^2\left(x-\frac12\right)\mathrm{d}x=\left[\dfrac{x^2}{2}-\dfrac{x}{2}\right]_0^2=2-1=1\) M1
  2. But \(\mathrm{f}(0)=-\dfrac12<0\), so the first property fails A1

Answer: No. The area is 1, but \(\mathrm{f}(x)<0\) for \(0\le x<\frac12\).

Quick checks

Quick check 1

The continuous random variable \(X\) has PDF \(\mathrm{f}(x)=kx\) for \(0\le x\le4\), and \(\mathrm{f}(x)=0\) otherwise. Find the value of the constant \(k\).

Worked solution
  1. \(\displaystyle\int_0^4kx\,\mathrm{d}x=k\left[\dfrac{x^2}{2}\right]_0^4=8k=1\)

Answer: \(k=\frac18=0.125\)

Quick check 2

The continuous random variable \(X\) has PDF \(\mathrm{f}(x)=kx^2\) for \(0\le x\le3\), and \(\mathrm{f}(x)=0\) otherwise. (a) Find the value of \(k\). (b) Find \(\mathrm{P}(X<2)\).

Worked solution
  1. (a) \(k\left[\dfrac{x^3}{3}\right]_0^3=9k=1\), so \(k=\dfrac19\)
  2. (b) \(\displaystyle\int_0^2\dfrac{x^2}{9}\,\mathrm{d}x=\left[\dfrac{x^3}{27}\right]_0^2=\dfrac{8}{27}\)

Answer: (a) \(\frac19\) (b) \(\frac{8}{27}\approx0.296\)

Quick check 3

The continuous random variable \(X\) has PDF \(\mathrm{f}(x)=k(4-x)\) for \(0\le x\le4\), and \(\mathrm{f}(x)=0\) otherwise. Find \(\mathrm{P}(X>1)\).

Worked solution
  1. Triangle: \(\dfrac12\times4\times4k=1\), so \(k=\dfrac18\)
  2. \(\mathrm{P}(X>1)=\dfrac12\times3\times3k=\dfrac{9}{16}\)

Answer: \(\frac{9}{16}=0.5625\)

Quick check 4

The continuous random variable \(X\) has PDF \(\mathrm{f}(x)=\dfrac{k}{x^2}\) for \(1\le x\le2\), and \(\mathrm{f}(x)=0\) otherwise. (a) Find the value of \(k\). (b) Find \(\mathrm{P}(X>1.5)\).

Worked solution
  1. (a) \(k\left[-\dfrac1x\right]_1^2=k\left(1-\dfrac12\right)=1\), so \(k=2\)
  2. (b) \(2\left[-\dfrac1x\right]_{1.5}^2=2\left(\dfrac23-\dfrac12\right)=\dfrac13\)

Answer: (a) 2 (b) \(\frac13\approx0.333\)
