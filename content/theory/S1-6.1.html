6.1 Discrete random variables

Based on Cambridge International AS & A Level Mathematics: Probability & Statistics 1 Coursebook (Dean Chalmers), Chapter 6 Probability distributions, printed p.150. Own wording and new numbers, following the coursebook introduction to discrete random variables.

Key words: discrete random variable, probability distribution

What is a random variable?

A random variable is a quantity whose value depends on the outcome of a random experiment. We use a capital letter such as \(X\) for the random variable and a small letter such as \(x\) for a value it can take. For example, if two coins are tossed, the number of heads \(X\) can be 0, 1 or 2.

A discrete random variable can take only particular separate values, often whole numbers that come from counting. The number of sixes in ten rolls of a die is discrete. A length or a time measured on a continuous scale is not.

\(P(X=x)\) means the probability that \(X\) takes the value \(x\). Because exactly one value must occur, the probabilities of all the possible values add up to 1:

\[\sum P(X=x)=1,\qquad 0\le P(X=x)\le 1.\]

This fact is used to find an unknown constant in a probability distribution.

Worked example 1: Finding a constant

Coursebook, 6.1, discrete random variables. New numbers.

\(X\) takes the values 2, 3 and 5 only, with \(P(X=x)=kx\). Find \(k\) and \(P(X\ge 3)\).

  1. \(2k+3k+5k=1\) M1
  2. \(10k=1\), so \(k=0.1\) A1
  3. \(P(X\ge 3)=0.3+0.5=0.8\) A1

Answer: \(k=0.1\), \(P(X\ge 3)=0.8\)

Worked example 2: Rejecting an impossible value

Coursebook, 6.1, discrete random variables. New numbers.

The probabilities of the values of \(X\) are \(0.2\), \(3p\), \(p^2\) and \(0.4\). Find \(p\).

  1. \(0.2+3p+p^2+0.4=1\), so \(p^2+3p-0.4=0\) M1
  2. \(p=\dfrac{-3\pm\sqrt{9+1.6}}{2}\), so \(p=0.128\) or \(p=-3.13\) A1
  3. A probability cannot be negative, so \(p=0.128\) (3 s.f.). A1

Answer: \(p=0.128\)

Common mistakes

  • Forgetting to check that every probability is between 0 and 1. Reject any value of a constant that makes a probability negative or bigger than 1.
  • Writing \(P(X\gt 2)\) when the question means \(P(X\ge 2)\). Read the inequality carefully.
  • Adding the values of \(X\) instead of the probabilities when using \(\sum P(X=x)=1\).

Quick check 1

\(X\) takes the values \(1, 2, 3, 4\) only, and \(P(X=x)=kx\). Find \(k\).

Worked solution
  1. \(k(1+2+3+4)=1\), so \(10k=1\).

Answer: \(k=0.1\)

Quick check 2

\(X\) takes the values 0, 1, 2 and 3 only, with \(P(X=0)=0.15\), \(P(X=1)=0.35\) and \(P(X=2)=0.3\). Find \(P(X=3)\).

Worked solution
  1. \(1-(0.15+0.35+0.3)=1-0.8\)

Answer: \(0.2\)

Quick check 3

\(X\) takes the values \(1, 2, 3\) only, and \(P(X=x)=kx^2\). Find \(P(X=3)\).

Worked solution
  1. \(k(1+4+9)=1\), so \(k=\dfrac{1}{14}\).
  2. \(P(X=3)=\dfrac{9}{14}\)

Answer: \(\dfrac{9}{14}=0.643\) (3 s.f.)
