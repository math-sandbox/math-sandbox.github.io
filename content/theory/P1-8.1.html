8.1 Increasing and decreasing functions

Based on Cambridge International AS & A Level Mathematics: Pure Mathematics 1 Coursebook (Sue Pemberton, series editor Julian Gilbey), Chapter 8 Further differentiation, printed pp.213–215. Own wording and new numbers, following the coursebook link between the sign of the derivative and increasing or decreasing functions.

Key words: increasing function, decreasing function, derivative

The sign of the derivative

A function \(f\) is increasing on an interval if \(f(x)\) gets larger as \(x\) increases, and decreasing if \(f(x)\) gets smaller. The sign of the gradient tells us which:

  • \(f'(x)\gt 0\) for all \(x\) in an interval: \(f\) is increasing there.
  • \(f'(x)\lt 0\) for all \(x\) in an interval: \(f\) is decreasing there.

A function that is increasing for all values in its domain is called an increasing function. If \(f'(x)\) is positive for some \(x\) and negative for others, \(f\) is neither.

Showing the sign

To show that \(f'(x)\) is always positive, complete the square, for example \(3x^2-6x+5=3(x-1)^2+2\gt 0\), or show that a quadratic with positive leading coefficient has negative discriminant. For a restricted domain, check the sign of each term.

Worked example 1: Finding where a function increases

Coursebook, 8.1, increasing and decreasing. New numbers.

Find the set of values of \(x\) for which \(f(x)=2x^3-9x^2+12x\) is decreasing.

  1. \(f'(x)=6x^2-18x+12=6(x-1)(x-2)\) M1 A1
  2. \(f'(x)\lt 0\) between the roots M1
  3. \(1\lt x\lt 2\) A1

Answer: \(1\lt x\lt 2\)

Worked example 2: An increasing function

Coursebook, 8.1, showing a function is increasing. New numbers.

Show that \(f(x)=x^3+3x^2+5x\) is an increasing function.

  1. \(f'(x)=3x^2+6x+5\) B1
  2. \(=3(x+1)^2+2\) M1
  3. \(3(x+1)^2\ge 0\), so \(f'(x)\ge 2\gt 0\): increasing. A1

Answer: \(f'(x)\gt 0\) for all \(x\)

Common mistakes

  • Showing \(f'(x)\gt 0\) at one value only. You must show it for every \(x\) in the domain.
  • Ignoring a restricted domain such as \(x\lt -1\).
  • Giving the answer about \(f(x)\) instead of about \(f'(x)\): the sign that matters is the sign of the derivative.

Past paper

9709/12/F/M/20 Q1, official QP and official MS.

The function \(f\) is defined by \(f(x)=\dfrac{1}{3x+2}+x^2\) for \(x<-1\).

Determine whether \(f\) is an increasing function, a decreasing function or neither. [3]

Mark scheme
  1. \(f'(x)=-(3x+2)^{-2}\times3\) B1 Official MS: B2, 1, 0 for f′(x) = −(3x + 2)⁻² × [3] + [2x]; one mark for each correct bracketed part.
  2. \(+2x\) B1 Official MS: second mark of the B2, 1, 0.
  3. For \(x<-1\) both terms are negative, so \(f'(x)<0\) and \(f\) is decreasing. B1 Official MS: B1, dependent on at least B1 for f′(x) and must include ‘(always) negative’.

Quick check 1

\(f(x)=x^2-6x+2\) is increasing for \(x\gt k\). Find \(k\).

Worked solution
  1. \(f'(x)=2x-6\gt 0\)

Answer: \(k=3\)

Quick check 2

\(f(x)=x^3-12x\) is decreasing for \(-p\lt x\lt p\). Find \(p\).

Worked solution
  1. \(3x^2-12\lt 0\), so \(x^2\lt 4\).

Answer: \(p=2\)

Quick check 3

Find the least \(k\) for which \(f(x)=x^3-6x^2+kx\) is an increasing function.

Worked solution
  1. \(f'(x)=3x^2-12x+k\)
  2. Discriminant \(144-12k\le 0\)

Answer: \(k=12\)
