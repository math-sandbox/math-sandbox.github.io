22.3 Functions and function notation

Based on Cambridge IGCSE Mathematics Core and Extended Coursebook (Karen Morrison and Nick Hamshaw), Chapter 22 More equations, formulae and functions. The wording is original and follows the published section titles and the standard Cambridge IGCSE treatment of the topic. Printed pp.768–780.

Key words: function, composite function, inverse function

Function notation

A function is a rule that gives exactly one output for each input. We write \(f(x)=2x+3\), or \(f:x\mapsto 2x+3\). \(f(4)\) means the output when the input is 4, so \(f(4)=11\). You can also substitute an expression: \(f(3x)=2(3x)+3=6x+3\).

Composite functions

\(fg(x)\) means \(f\bigl(g(x)\bigr)\): apply \(g\) first, then apply \(f\) to the result. In general \(fg(x)\) and \(gf(x)\) are different.

Inverse functions

The inverse function \(f^{-1}\) undoes \(f\). To find it, write \(y=f(x)\), rearrange to make \(x\) the subject, then write the answer in terms of \(x\). For example, if \(f(x)=2x+3\), then \(x=\dfrac{y-3}{2}\), so \(f^{-1}(x)=\dfrac{x-3}{2}\).

Worked example 1: Composite functions

Coursebook, 22.3, composite functions. New numbers.

\(f(x)=x^2\) and \(g(x)=x-4\). Find (a) \(fg(1)\) and (b) \(gf(x)\).

  1. (a) \(g(1)=-3\), so \(fg(1)=(-3)^2=9\) M1 A1
  2. (b) \(gf(x)=g(x^2)=x^2-4\) B1

Answer: (a) \(9\) (b) \(x^2-4\)

Worked example 2: An inverse function

Coursebook, 22.3, inverse functions. New numbers.

\(h(x)=\dfrac{x+1}{5}\). Find \(h^{-1}(x)\) and \(h^{-1}(4)\).

  1. \(y=\dfrac{x+1}{5}\), so \(5y=x+1\) and \(x=5y-1\) M1
  2. \(h^{-1}(x)=5x-1\) A1
  3. \(h^{-1}(4)=19\) B1

Answer: \(h^{-1}(x)=5x-1\), \(19\)

Common mistakes

  • Working out \(fg(x)\) in the wrong order. Apply the function nearest to \(x\) first.
  • Confusing \(f^{-1}(x)\) with \(\dfrac{1}{f(x)}\).
  • Multiplying \(f(x)\) by \(g(x)\) instead of substituting one into the other.

Past paper

0580/23/M/J/17 Q12, official QP and official MS.

\(f(x)=3+4x\qquad g(x)=6x+7\)

Find, in its simplest form,

(a) \(f(3x)\), [1]

(b) \(fg(x)\). [2]

Mark scheme
  1. (a) \(f(3x)=3+12x\) B1 Official MS: 3 + 12x final answer, 1 mark.
  2. (b) \(fg(x)=3+4(6x+7)\) M1 Official MS: M1 for 3 + 4(6x + 7).
  3. (b) \(=24x+31\) A1 Official MS: 24x + 31 final answer, 2 marks.

Past paper

0580/21/O/N/19 Q24, official QP and official MS.

\(f(x)=3x-5\qquad g(x)=2^x\)

(a) Find \(fg(3)\). [2]

(b) Find \(f^{-1}(x)\). [2]

Mark scheme
  1. (a) \(g(3)=2^3=8\), \(f(8)=3\times8-5\) M1 Official MS: M1 for 3(2^x) − 5 soi or for f(8).
  2. (a) \(fg(3)=19\) A1 Official MS: 19, 2 marks.
  3. (b) \(y=3x-5\), so \(y+5=3x\) (or swap: \(x=3y-5\)) M1 Official MS: M1 for a correct first step, e.g. y + 5 = 3x or y/3 = x − 5/3 or x = 3y − 5.
  4. (b) \(f^{-1}(x)=\dfrac{x+5}{3}\) A1 Official MS: (x + 5)/3 OE final answer, 2 marks.

Quick check 1

\(f(x)=3x+4\) and \(g(x)=2x+1\). Find \(fg(3)\).

Worked solution
  1. \(g(3)=7\)
  2. \(f(7)=21+4\)

Answer: \(25\)

Quick check 2

\(f(x)=4x+3\). Find \(f^{-1}(23)\).

Worked solution
  1. \(f^{-1}(x)=\dfrac{x-3}{4}\)
  2. \(f^{-1}(23)=\dfrac{20}{4}\)

Answer: \(5\)

Quick check 3

\(f(x)=2x+3\) and \(g(x)=3x+1\). Solve \(fg(x)=29\).

Worked solution
  1. \(fg(x)=2(3x+1)+3=6x+5\)
  2. \(6x+5=29\), so \(6x=24\).

Answer: \(x=4\)
