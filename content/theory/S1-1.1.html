1.1 Types of data

Based on Cambridge International AS & A Level Mathematics: Probability & Statistics 1 Coursebook (Dean Chalmers), Chapter 1 Representation of data, printed p.2 (and the formal statement of Key point 1.1 at the top of p.3). Own wording and new examples.

Key words: qualitative data, quantitative data, discrete data, continuous data

Qualitative and quantitative data

There are two types of data. Qualitative data (also called categorical data) are described in words and are non-numerical. Blood type, favourite subject and the colour of a car are qualitative. Quantitative data take numerical values. They are either discrete or continuous.

Discrete and continuous data

As a general rule, discrete data are counted and cannot be made more precise, whereas continuous data are measurements given to a chosen degree of accuracy.

Key point. Discrete data can take only certain values. Continuous data can take any value, possibly within a limited range.

The diagram below shows isolated, allowed values, which is the typical picture for discrete data.

The number of letters in the words of a book is discrete quantitative data: each word has 1 or 2 or 3 or 4 or more letters, never 3.5 letters. Discrete data need not be integers. The dollar values of United States coins, such as 0.01, 0.05, 0.10, 0.25, 0.50 and 1.00, form a discrete set, and shoe sizes such as 6, \(6\frac{1}{2}\) and 7 are also discrete.

The next diagram shows an interval of allowed values, which is the typical picture for continuous data.

The times taken by athletes to run 100 metres are continuous quantitative data. We may record those times to the nearest second or to a tenth of a second, or more accurately if the equipment allows, but the underlying variable can take any value in a range of positive real numbers. Recording a continuous measurement to a given accuracy does not make the data discrete.

Worked example 1: Classifying variables

Book: pages 2–3 (Key point 1.1); new list

State whether each of the following is qualitative, discrete quantitative or continuous quantitative: the colour of a student’s bag; the number of siblings a student has; the time in seconds to run 100 metres; a student’s shoe size; a student’s blood type.

  1. Colour of bag and blood type are described in words, so both are qualitative. B1
  2. The number of siblings is a count of whole numbers only, so it is discrete quantitative. Shoe size takes only certain values (including half sizes), so it is also discrete quantitative. B1
  3. Time to run 100 metres is a measurement that can, in principle, take any value in a range, so it is continuous quantitative. B1

Answer: qualitative; discrete quantitative; continuous quantitative; discrete quantitative; qualitative

Worked example 2: Non-integer discrete values

Book: page 3 (coin values and shoe sizes); new numbers

A vending machine accepts only coins with values 0.20, 0.50 and 1.00 dollars. A student says that these values cannot be discrete because they are not integers. Comment, and classify the mass of each coin, measured in grams.

  1. Discrete data can take non-integer values. The allowed coin values form a list of certain numbers only, so the value of a coin is discrete quantitative. B1
  2. Mass is a measurement that can take any value in a range (to a chosen accuracy), so the mass of a coin is continuous quantitative. B1

Answer: the coin values are discrete quantitative; mass is continuous quantitative

Common mistakes

  • Thinking that discrete data must be integers. Coin values and half shoe sizes are discrete but not integers.
  • Thinking that a continuous measurement becomes discrete just because it is recorded to the nearest centimetre or second.
  • Treating a coded category such as “1 for red, 2 for blue” as quantitative: the numbers are labels, so the data are still qualitative.

Quick checks

Quick check 1

How many of the following four variables are quantitative: favourite sport; number of pets; length of a desk in centimetres; type of public transport used?

Worked solution
  1. Favourite sport and type of public transport are qualitative. Number of pets and length of a desk are quantitative, so 2 of the four variables are quantitative.

Answer: \(2\)

Quick check 2

How many of the following four variables are discrete: number of typographical errors on a page; temperature of a room in degrees Celsius; shoe size; height of a tree in metres?

Worked solution
  1. Number of typographical errors and shoe size are discrete. Temperature and height are continuous measurements, so 2 of the four variables are discrete.

Answer: \(2\)

Quick check 3

A list of 12 recorded values consists of 5 car colours, 4 counts of the number of doors and 3 lengths in metres. How many of these 12 recorded values are quantitative?

Worked solution
  1. The 5 colours are qualitative. The 4 door-counts and the 3 lengths are quantitative, so \(4+3=7\) of the values are quantitative.

Answer: \(7\)

Marks: M = method, A = accurate answer (depends on M), B = independent mark. Marks on worked examples are illustrative, not official. Give exact integers unless a question says otherwise. Discrete data can take only certain values (not necessarily integers); continuous data can take any value in a range.
